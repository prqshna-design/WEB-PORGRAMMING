Topic 02: The <form> Element

The <form> element groups form controls and defines how their data is submitted. Two important attributes are action and method. 

<!-- action: destination URL | method: GET or POST -->
<form action="/submit" method="POST">
  <input name="username">
  <button type="submit">Submit</button>
</form>

Method 1: GET Request

GET appends submitted form values to the URL as query parameters. Try submitting a username and observe the address bar.

GET: Form data appears in the URL, so it is useful for searches and filters. Do not submit passwords or other sensitive information through GET.

Method 2: POST Request

POST sends form data in the request body rather than appending it to the URL. This demo shows the idea without sending data to a server.

POST: Commonly used to submit or create data. A real POST request requires a server endpoint to process it. POST alone does not encrypt data; use HTTPS for secure transmission.
