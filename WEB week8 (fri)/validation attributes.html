HTML5 Validation Attributes

HTML5 provides built-in validation attributes that help prevent invalid form submissions without requiring JavaScript for the validation rules themselves.

Try these validation rules:
  • Name must contain at least 3 characters.
  • Student ID must contain exactly 9 digits.
  • Course score must be between 0 and 100.
Your browser checks these constraints when you submit.
