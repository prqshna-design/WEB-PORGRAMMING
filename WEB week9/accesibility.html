Week 9: Web Accessibility

In this task, I used Google Lighthouse to test the accessibility of my Web Programming portfolio. I recorded the initial results, made accessibility improvements, and ran the audit again.

Before and After Lighthouse Results

These screenshots show my Lighthouse accessibility results before and after the improvements.

Accessibility Improvements

I made the following changes to improve the accessibility of my website:

  1. Skip Link: Added a skip link as the first element inside the body. It allows keyboard users to jump directly to the main content.
  2. Main Landmark: Used the main HTML element to identify the primary content for screen readers and assistive technologies.
  3. Keyboard Focus: Added a visible 3px focus outline using :focus-visible to help keyboard users identify the currently selected element.
  4. Image Alternative Text: Added descriptive alt text to both Lighthouse screenshots so screen readers can identify their purpose.
  5. Color Contrast: Used darker text colors against light backgrounds to improve readability.
  6. Heading Structure: Organized headings using a logical h1 and h2 hierarchy.
