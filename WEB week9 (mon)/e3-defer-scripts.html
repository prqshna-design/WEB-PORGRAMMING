WEEK 9 · EXERCISE 3

Defer JavaScript Loading

Learning how the defer attribute helps improve the loading process of a webpage.

Objective

The objective of this exercise is to understand how JavaScript affects HTML parsing and how the defer attribute allows an external JavaScript file to download without blocking HTML parsing.

What Does Defer Do?

Normally, a regular script can pause HTML parsing while the browser downloads and executes it. When the defer attribute is used with an external script, the browser downloads the script while parsing HTML and executes it after the HTML has been parsed.

Before Optimization

A normal external script without defer:

<script src="script.js"></script>

This can block HTML parsing while the script is downloaded and executed.

After Optimization

Using the defer attribute:

<script src="script.js" defer></script>

The browser can continue parsing HTML while downloading the script. The script executes after HTML parsing is complete.
