WEEK 9 · MONDAY

Performance Optimization

Improving my personal portfolio website by applying performance optimization techniques and comparing Lighthouse results.

01. Assignment Overview

The goal of this assignment was to analyze the performance of my personal website using Google Lighthouse, apply at least three optimization techniques, and run Lighthouse again to compare the results.

02. Before Optimization

99

Initial Performance Score

My website received a Performance score of 98 before applying the optimizations.

03. Optimizations Applied

1

Optimized Google Fonts Loading

Added preconnect to Google Fonts and its font server to establish connections earlier and improve font loading.

2

Improved JavaScript DOM Rendering

Used DocumentFragment to group dynamically created cards before adding them to the page, reducing repeated DOM updates.

3

Minified CSS

Removed unnecessary spaces and line breaks from the CSS code to reduce its size and make the stylesheet more compact.

05. Reflection

Through this assignment, I learned how small changes in font loading, JavaScript rendering, and CSS can help improve website performance. Comparing the Lighthouse reports helped me understand the importance of testing and optimizing a website instead of focusing only on its appearance.
