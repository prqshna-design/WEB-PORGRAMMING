WEEK 9 · EXERCISE 2

Image Format Optimization

Exploring modern image formats and reducing image file sizes to improve website loading performance.

01. Objective

The objective of this exercise is to understand different image formats and learn how converting images into modern formats such as WebP can reduce file sizes and improve website performance.

02. Image Format Comparison

Different image formats use different compression methods. Choosing the right format can help reduce the amount of data a browser needs to download.

Format Characteristics Common Use
JPG / JPEG Lossy compression Photographs
PNG Supports transparency and lossless compression Graphics and screenshots
WebP Supports lossy and lossless compression Optimized website images

03. Original Image (PNG)

This is my original image before optimization. It was saved in PNG format.

PNG Original image format
3,534 KB Original file size

04. Optimized Image (WebP)

I converted the same original image into WebP format. The optimized version has a much smaller file size.

WebP Optimized image format
357 KB Optimized file size

05. File Size Comparison

Image Format File Size
Original Image PNG 3,534 KB
Optimized Image WebP 357 KB
File Size Saved — 3,177 KB
89.9% Reduction

Converting the original PNG image into WebP reduced its file size by approximately 89.9%. This means the optimized image requires significantly less data to download.

06. HTML Implementation

I used the HTML picture element to provide the WebP image with the original PNG as a fallback. 

<picture>
  <source
    srcset="images/optimized-image.webp"
    type="image/webp">

  <img
    src="images/original-image.png"
    alt="Optimized image"
    loading="lazy">
</picture>

07. What I Learned

Through this exercise, I learned that image optimization can significantly reduce the size of website resources. By converting my original PNG image into WebP, I reduced its file size by 89.9%, which can help improve loading performance while maintaining visually acceptable image quality.
