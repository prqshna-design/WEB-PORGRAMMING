Week 9: Web Accessibility

In this task, I used Google Lighthouse to test the accessibility of my Web Programming portfolio. I recorded the initial results, made accessibility improvements, and ran the audit again.

Before and After Lighthouse Results

These screenshots show my Lighthouse accessibility results before and after the improvements.

Three Accessibility Fixes

  1. Skip link: Added a skip link that allows keyboard users to jump directly to the main content.
  2. Main landmark: Added a main element to identify the primary content for assistive technologies.
  3. Keyboard focus and contrast: Improved visible keyboard focus indicators and adjusted colors to help users see and read the content more easily.
